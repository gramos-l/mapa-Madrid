Necesitas una clave de Google

Este modo usa «Photorealistic 3D Tiles» de Google (edificios reales con fotografías). No es gratuito por defecto y no funciona sin tu propia clave:

  1. En Google Cloud, crea un proyecto y activa la facturación.
  2. Activa la API Map Tiles API y crea una clave.
  3. Restringe la clave al sitio https://gramos-l.github.io/* (la clave será visible en esta página).
  4. Revisa el precio y los términos para tu país: Google indica que pueden cambiar para cuentas del Espacio Económico Europeo.

La clave se guarda solo en este navegador. No se sube a ningún sitio.
